# Interactive Quiz Game

## About the Project
This project is an interactive multiple-choice quiz game developed using HTML, CSS, and JavaScript as part of my Frontend Web Development Internship at Barakah TechLabs.

## Features
- Welcome screen with a Start Quiz button
- Five multiple-choice questions
- Four answer options for each question
- Instant correct and incorrect answer feedback
- Automatic score calculation
- Progress bar to track quiz progress
- Final score and result message
- Play Again functionality
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## Design
The project uses a Midnight Navy and Gold colour theme to create a clean, elegant, and professional interface.

## Learning Outcomes
- Practised JavaScript functions and event listeners
- Learned DOM manipulation
- Used conditional statements and arrays
- Implemented interactive buttons and score tracking
- Improved HTML and CSS styling skills

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Click Start Quiz to begin.
